# AI 学习管理（静态网页）

一个用来管理自己人工智能专业学习的小网站：没有构建步骤、没有后端、没有依赖，三个文件就是全部。
所有数据保存在你自己浏览器的 localStorage 里，不上传服务器。

## 页面结构

打开网站先看到**主界面**：三个正方形入口（「我的学习路线」「向 AI 提问」「学习笔记」），方块上只有名字。

点任一个方块进入对应的**子界面**，子界面左上有「← 返回」可以回到主界面；点左上角标题「AI 学习管理」也能回到主界面。
网址会带锚点（如 `#notes`），刷新后仍停在同一个子界面。

界面配色固定为**白色背景**（已按需求移除深色模式适配）；想换主色只改 `style.css` 开头 `:root` 里的 `--accent`。

| 子界面 | 作用 |
| --- | --- |
| ① 学习路线 | 把整条学习路线拆成若干阶段，每个阶段可标记「未开始 / 学习中 / 已完成」，顶部有进度条，一眼看出学到哪、下一步学什么。可增删、上下移动。 |
| ② 向 AI 提问 | 一个对话窗口，直接调用大模型 API 回答你的学习问题，**支持上传图片和文件**。回答会留在页面上，成为你的资料。 |
| ③ 学习笔记 | 二级入口，里面再分三个方形板块：**学习卡片**（原有功能：随手记知识点，可加标签、搜索、删除）、**手写笔记**（画板）、**AI 问答笔记**（问答沉淀）。 |

### 学习笔记的三个子板块

| 子板块 | 状态 | 说明 |
| --- | --- | --- |
| 学习卡片 | ✅ 完整功能 | 原来「学习笔记」的全部功能搬到这里，数据键仍是 `aiStudy.notes.v1`（**旧数据不会丢**）。 |
| 手写笔记 | 🚧 框架 | 用鼠标/手指直接写画：画笔、橡皮、粗细、撤销、清空、保存为图片。笔画以矢量形式存在本机（`aiStudy.handwriting.v1`），刷新后还在。后续可加：多页、插入学习卡片、双指缩放。 |
| AI 问答笔记 | 🚧 框架 | 手动记录「问题 + 答案/要点 + 标签」，可搜索、删除（`aiStudy.qaNotes.v1`）。后续可加：从「向 AI 提问」一键收藏某轮问答。 |

底部还有 **导出备份 / 导入备份**（JSON 文件），用于换电脑或清缓存前保存数据。

## 使用第 ② 板块（需要一次设置）

纯静态网页没有后端，所以浏览器会**直接用你自己的 API Key** 调用模型接口。

1. 打开 <https://platform.deepseek.com/api_keys>，注册并创建一个 API Key（形如 `sk-...`）。
2. 在网页里展开「AI 设置」，把 Key 粘进去，点「保存到本机」。
3. 之后就能直接在输入框提问了。

默认接口 `https://api.deepseek.com`、模型 `deepseek-flash`，都可以在设置里改
（任何 OpenAI 兼容接口都可以，例如换成 Kimi 的 `https://api.moonshot.cn/v1`）。

### 上传图片和文件

三种方式：点「＋ 添加图片 / 文件」、把文件**拖到附件区**、或直接在输入框里 **Ctrl + V 粘贴截图**。

| 类型 | 支持情况 | 说明 |
| --- | --- | --- |
| 图片 | ✅ png / jpg / jpeg / gif / webp | 直接按 base64 发送（OpenAI 兼容的 `image_url` 块）。 |
| 图片（其他格式） | ✅ 浏览器能解码的都行（BMP / TIFF / AVIF / SVG 等） | 会自动用 canvas 转成 JPEG 再发送。 |
| 大图 | ✅ 超过 3 MB 自动压缩 | 缩到最长边 1600 像素、JPEG 质量 0.85；实测 8 MB 的照片会压到 1 MB 以内。 |
| iPhone 的 HEIC | ⚠️ 看浏览器 | Safari 能解码 HEIC，会自动转成 JPEG；Chrome/Edge 解不了，会提示你在相册里导出成 JPEG。 |
| 文本类文件 | ✅ txt / md / csv / json / 各类代码 | 在浏览器里读取文字，作为「【附件：文件名】+ 内容」拼进问题。单文件上限 1 MB，最多带入 2 万字符。 |
| PDF / Word / PPT | ❌ 暂不支持 | 接口的 Files API 只收图片。请**截图后按图片上传**，或把关键段落复制进问题。 |

被拒绝或自动处理的文件会在附件区显示说明文字，不会静默失败。

模型与图片的关系（重要）：

- `deepseek-flash` **支持图片**，且价格便宜、支持 100 万 token 上下文 —— 默认就用它。
- `deepseek-v4-pro` 更强但**不支持图片**，而且贵得多。
- 用不支持图片的模型带图提问时，网页会拦下来并提示你切换模型，不会白花一次请求。

### 深度思考（可选）

「AI 设置」里有个「深度思考」开关，默认**关闭**（更快更省）。打开后请求会带
`thinking: {type: "enabled"}` 和 `reasoning_effort: "high"`，回答前会先推理，
适合啃难题；思考过程会在回答下方以「查看思考过程」折叠展示（最多保存 5000 字符）。
注意：该参数只在接口地址包含 `deepseek` 时发送，换别的服务商不会被这个字段干扰。

### 公式与富文本显示

AI 的回答会按 Markdown 渲染，数学公式用 **KaTeX** 排版：

- 行内公式 `$E = mc^2$`、独立公式 `$$\int_0^\infty e^{-x^2}dx$$` 都会渲染成真正的数学排版；
- 支持标题、列表、加粗、斜体、引用、代码块、表格；
- **每个代码块右上角有「复制」按钮**，点一下复制该段代码，按钮会短暂显示「已复制」；
  代码块横向滚动时按钮固定不动；复制失败（极少数老浏览器）会显示「复制失败」。
- `α β ∑ ≤ →` 等普通符号直接显示；
- 模型输出属于外部内容，所以渲染前会用 DOMPurify 净化，并禁用 `img/iframe/script/style`、
  只允许 `http(s)/mailto/#` 链接 —— 防止回答里藏脚本（页面本地存着你的 API Key）。

这些库都放在本站 `vendor/` 目录里（KaTeX + marked + DOMPurify，共约 620 KB，含字体），
**不依赖任何外部 CDN**，断网或 CDN 被墙也能正常显示公式。

### 安全须知（重要）

- Key 只保存在**你自己浏览器的 localStorage** 里，不会写进网页文件，也不会随代码上传。
- ⚠️ **绝对不要**把 Key 写进 `app.js` / `index.html`。这个仓库是公开的，写进去等于公开泄露。
- 公用电脑上用完请点「清除 Key」。
- 费用按用量计算；DeepSeek 的价格很低，日常学习提问花费很少。
- 图片只在**当前这次会话内存**里保存，用来随后的追问；对话记录里只留文件名。
  刷新页面后旧图片不再重复上传（省钱），需要时重新附一次即可。

## 数据存在哪里

| 内容 | 存放位置 |
| --- | --- |
| 学习路线 / 对话记录 / 笔记 | 你浏览器的 localStorage（键名 `aiStudy.*.v1`） |
| API Key | 同上，且**不会**被导出到备份文件里 |

也就是说：**换浏览器、换电脑、清理浏览器缓存都会看不到数据**，重要内容请用「导出备份」保存。
导出的 JSON 里不含 API Key，可以安全地放进网盘。
